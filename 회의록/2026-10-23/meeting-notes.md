## 논의 사항

### 1. GitHub 연구계획서 리뷰

- 주제: 범용 한국어 NER 모델에 금융 도메인을 추가 학습했을 때의 효과와 한계.
- 1단계: 일반 뉴스 NER 기본 모델. 개수가 충분한 4종(OG·CV·AF·TM)을 17개 분야 균형으로 학습한다.
- 2단계: 금융 특화 NER. 금융 라벨 8종(FIN_ORG·ORG·FIN_PRODUCT·MONEY·RATE·DATE·INDICATOR·POLICY)을 추가 학습한다.
- 기준선: klue/roberta-base, 학습 30만 문장 기준 dev F1 0.7466, test F1 0.7306.
- 학습은 규칙·사전 선라벨(실버셋)으로, 평가는 사람이 검수한 골드셋 500문장으로만 한다.

### 2. 10/22 1단계 실험 리뷰

팀원 실험을 같은 채점기·같은 dev/test로 모아 비교했다. 기준선(dev 0.7466 / test 0.7306) 대비 dev F1 0.7점 이상 차이가 나야 의미 있다고 본다.

| 실험 | 실행자 | dev F1 | test F1 | 판정 |
| --- | --- | --- | --- | --- |
| 앙상블(6개 모델, 4표 이상) | 최세진 | 0.7812 | 0.7691 | 높음 |
| roberta-base, 데이터 60만 | 최세진 | 0.7649 | 0.7511 | 높음 (+1.83) |
| roberta-base + CRF | 최세진 | 0.7597 | 0.7474 | 높음 (+1.31) |
| 기준선 (roberta-base, 30만) | 최세진 | 0.7466 | 0.7306 | — |
| roberta-large, lr 2e-5 | 김병석 | 0.7456 | 0.7358 | 차이 없음 |
| 기준선 재현 | 진태현 | 0.7428 | 0.7303 | 차이 없음 |
| 5에폭 | 진태현 | 0.7426 | 0.7332 | 차이 없음 |
| lr 3e-5 | 박규태 | 0.7426 | 0.7310 | 차이 없음 |
| KoELECTRA | 최세진 | 0.7387 | 0.7295 | 낮음 |
| lr 2e-5 | 박규태 | 0.7367 | 0.7291 | 낮음 |
| 가중 손실 | 최세진·진태현 | 0.7293~0.7338 | 0.7180~0.7230 | 낮음 |

- **데이터 양이 모델 선택보다 중요하다.** 단일 모델 중 기준선을 넘은 것은 60만과 CRF뿐이다. 큰 모델·학습률·에폭·KoELECTRA는 차이가 없거나 낮았다.
- **설정 근거:** 5에폭이 3에폭보다 낫지 않아 에폭 3 유지. 학습률은 기본 5e-5 유지.
- **가중 손실은 전체 F1을 낮춘다**(3회 모두 −1.3~−1.7점). 대신 신조어(NW)는 0.60 → 0.74로 올랐다.
- **드문 태그 보강은 역효과.** TR·FD로 라벨된 말을 모아 넣었지만 test에서는 같은 말에 라벨이 없는 경우가 많아 라벨 일관성 문제가 커졌다.
- **앙상블이 가장 큰 개선:** 단일 최고(60만)보다 test +1.80점. roberta-large와 60만 모델이 서로 가장 잘 보완했다.
- **정답 데이터 오류:** 6개 모델이 모두 못 맞힌 test 정답 2,379개(15.9%) 대부분은 정답 쪽 문제다. 전처리에서 ‘대전시’ 안의 ‘시’ 같은 잘못된 정답이 생겨(test 2.1%) 고친 판 split_v3b를 만들었다. 다시 채점해도 순위는 같다.
- **진태현 기준선 재현**이 흔들림 범위 안에 들어 팀 실험 조건이 같음을 확인했다.
- **김현호**(klue/bert-base, 자체 코드) dev 0.7461은 정답 개체 수가 공용 채점기와 달라(12,967 vs 13,014) 비교에서 빠졌다. 최대 길이 256에서 잘린 개체로 추정.

### 4. 학습 데이터 확대 (30만 → 120만)

- roberta-base를 120만 문장(고친 정답 split_v3b)으로 학습했다: **dev 0.7875 / test 0.7773 / test macro 0.6569**. 60만 대비 dev +2.16점.
- 에폭별 dev: 0.7456 → 0.7727 → 0.7875. Colab A100 40GB에서 3.45시간.
- 앙상블(120만 + 60만 + AI Hub ELECTRA 2세부 30만, 2표 이상): dev 0.7952 / test 0.7836.
- 학습량 확대는 120만에서 마무리한다. 대용량 학습에 맞는 GPU 설정 코드가 필요하다.

### 5. 문제: 모델 가중치와 새 태그 학습

- 10/22까지의 학습 코드는 학습이 끝난 뒤 체크포인트를 지워 최종 가중치가 남아 있지 않다. 드라이브 휴지통을 확인 중이며, 없으면 고친 코드로 재학습한다.
- 코드는 10/23에 고쳐 이제 항상 가중치를 저장·확인한다.
- 2단계는 120만 모델 본체에 금융 태그용 분류층을 새로 달아, 새 태그에 특화되도록 학습한다.

### 6. 오전 회의 내용: 2단계 금융 라벨링

- 경제 뉴스 100만 문장을 5명이 20만 문장씩 나눠, 각자 Claude Code에서 Claude가 직접 라벨을 달게 했다(2단계 학습용 실버셋).
- 기준은 GUIDE.md(v1) 하나로 통일하고, 맞추기 10문장(F1 0.90 이상)을 통과한 뒤 50문장씩 라벨 → 자동 검사 → 저장을 반복한다.
- 결과는 export해 Notion ‘결과 올리기’ 표에 올린다. 골드셋 510문장은 이 100만에 없어 평가에만 쓴다.
