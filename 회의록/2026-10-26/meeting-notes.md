# 10월 26일 회의록 — NER 팀 4차

## 논의 사항

### 1. gpt-oss-20b 도메인 사전학습 (후보 #9)

- **목적:** OpenAI 공개 모델 gpt-oss-20b에 경제 기사 50만 문장을 더 읽혀(다음 단어 맞히기) 금융 문체에 익숙하게 만든다.
- **방식:** 본체(20B)는 고정하고 LoRA(작은 덧붙임 가중치)만 학습한다. 이 단계에서는 라벨(span)을 쓰지 않는다.
- **이후 계획:** 이 모델로 “문장 → 개체 목록을 글로 답하는” 방식의 금융 NER 파인튜닝을 하고, 인코더 모델 8개와 함께 비교한다.
- **데이터:** 경제 문장 말뭉치(econ_dapt.txt.gz, 295MB). 금융 골드셋 510문장과 Claude 라벨 표본 12,510문장은 미리 뺐다(평가 문장이 사전학습에 섞이지 않게).
- **예상 자원(추정):** 약 2,075만 토큰, 1,250스텝. GPU 메모리 50~65GB, 학습 1~3시간(준비 15~20분 별도), 10~25 CU.
- **런타임:** H100, G4(96GB), A100 80GB만 가능(70GB 이상). A100 40GB·L4·T4는 1번 셀에서 자동으로 멈춘다.

### 2. 현재 상태

- 구조가 같은 초소형 모델로 학습·저장·이어서 학습까지 시험을 통과했다.
- 실제 20B 모델은 아직 돌려 보지 않았다(첫 실행). 에러가 나면 출력 전체를 공유한다.
- 실행 담당은 아직 정하지 않았다.

### 3. 금융 라벨링 인계와 GUIDE.md v1.1 (10/26 기준)

**인계**

- 라벨링 인계 후 1200묶음 라벨링 진행

**GUIDE.md v1 → v1.1에서 바뀐 것** (2026-10-25)

v1 본문은 그대로이고, 세션마다 판단이 갈리던 18항목을 4-2장으로 추가했다. 5개 세션의 기준 제안을 모아, 그때까지 단 59,400문장에서 다수였던 쪽으로 정했다. 4-2장이 본문과 다르면 4-2장을 따른다.

| 표현 | 결정 |
| --- | --- |
| 벤처캐피탈·창투사 이름(미래에셋벤처투자 등) | FIN_ORG. 일반명 ‘벤처캐피탈’·‘창투사’는 안 달음 |
| 펀드평가사(제로인) / 금융정보 업체(와이즈에프엔, 에프앤가이드) | FIN_ORG / ORG |
| 상호금융기관 이름(새마을금고, 신협, 수협·농협 상호금융) | FIN_ORG. 일반명 ‘상호금융’·‘우체국’은 안 달음 |
| 무역협정(FTA, 한·중 FTA, CPTPP, RCEP) | POLICY |
| 뉴욕증시·중국 증시·국내 증시 | 안 달음. 다우지수·코스피 같은 지수 이름만 INDICATOR |
| 단독 ‘관세’ | 안 달음. 관세율은 INDICATOR, 관세청은 ORG |
| 리츠 회사 이름(롯데리츠) | FIN_PRODUCT (문맥이 회사여도) |
| 퇴직연금제도 / 퇴직연금 | POLICY / FIN_PRODUCT |
| 법정 최고금리(대부업·이자 상한) | POLICY |
| 최저임금 | 금액·인상 뜻 INDICATOR / 제도 뜻 POLICY (최저임금법은 POLICY) |
| 레버리지비율·수수료율 같은 비율 | 값·지표 뜻 INDICATOR / “~규제” 뜻 POLICY |
| DSR·LTV·DTI | 항상 POLICY (통계로 인용돼도) |
| 구·시·군 이름(강남구, 김포시) | 주소·지역 뜻 안 달음 / 기관으로 행동하면 ORG |
| 지난 분기, 지난주 | DATE 덩어리(‘지난해’와 같이 붙여 달음) |
| ‘72 퍼센트’, 전각 ％ | RATE (도구 경고는 무시) |
| 국제회계기준·IFRS·IFRS17·K-ICS | POLICY |
| 가상화폐 종목(이더리움, 리플) | FIN_PRODUCT |
| 운용사 뜻 ‘사모펀드’·‘PEF’ / 상품 뜻 사모펀드 | 안 달음 / FIN_PRODUCT (회사 이름 MBK파트너스만 FIN_ORG) |

- 이미 단 데이터 중 4-2장과 다른 라벨(무역협정 안 달음, 뉴욕증시 INDICATOR, 관세 POLICY, 주소 뜻 구·시 ORG 등)은 남아 있다. 학습 전에 일괄 정리할지 팀이 정한다.
- label_tool.py가 기록하는 기준서 버전 값은 아직 “GUIDE.md v1”이다.

**앞 작업자(최세진 님)가 정한 판단** — 같은 기준으로 맞춘다.

- 암호화폐 거래소(업비트·빗썸·코인원·코빗)는 FIN_ORG.
- 결제·교통카드 회사(한국스마트카드 등)는 ORG.
- 회사 이름이 DSR처럼 규제 약어와 같으면 달지 않는다.
- “우리·신한·하나은행”처럼 줄여 나열하면 끝의 ‘하나은행’만 FIN_ORG.

**품질 확인 (500묶음 시점 실측)**: 문장당 개체 2.20(기준 약 2.3), 개체 없는 문장 23.7%(기준 약 22%). 태그 비율도 기준과 비슷했다. 이어서 하는 동안 20묶음마다 확인한다.
