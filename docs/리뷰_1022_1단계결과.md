## 3. 해석

1. **데이터 양 > 모델 선택.** 60만(+1.83)과 CRF(+1.31)만 기준선을 넘었다. 큰 모델(roberta-large), 학습률, 에폭(5), KoELECTRA는 차이 없음 또는 낮음.
2. **가중 손실은 전체 F1을 낮춘다**(최세진·진태현 3번 모두 −1.3~−1.7점). 대신 드문 태그 NW는 오른다(0.60 → 0.74). 드문 태그가 중요할 때만 쓸 만하다.
3. **드문 태그 보강(D4_rare)과 TR 전문가는 오히려 드문 태그를 떨어뜨렸다.**
   - D4_rare vs 같은 수의 무작위(D4_rand): TR 0.437 vs 0.492, FD 0.432 vs 0.454, NW 0.493 vs 0.611.
   - TR 전문가: test TR 재현율 0.81이지만 정밀도 0.148(오탐 587개). CRF의 TR을 바꾸면 TR F1 0.48 → 0.25~0.29.
   - 원인(해석): 말뭉치 전체에서 TR·FD로 라벨된 문자열을 모아 넣었는데, 같은 말이 test에서는 라벨되지 않은 경우가 많다(라벨 일관성 문제). 드문 태그를 늘리면 그 불일치까지 커진다.
4. **데이터 정제 D3b(누락 보완)는 원 test에서 −0.51점.** test에도 같은 누락이 있어 예상된 결과. 골드셋 없이는 효과를 판단할 수 없다.
5. 진태현의 기준선 재현(ce_lossacc, dev 0.7428)이 최세진 기준선(0.7466)과 0.38점 차이로, 흔들림 범위 안에서 재현됨 → 팀 실험 조건이 맞는다는 확인.
