## 결정 1. 학습 문장 수 = 20만 (2026-10-22 02:30)

**기준 (결과 전에 정함)**: 6만 → 20만에서 dev F1 상승이 표본 흔들림 std(0.37점)의 2배인 **0.7점 미만이면 6만, 이상이면 20만**.

**측정** (klue/roberta-base, 3에폭, 서버 MIG 1g.10gb, split_v1 dev·test 고정, 작은 세트 ⊂ 큰 세트)

| 학습 문장 | dev F1 | dev macro F1 | test F1 | 학습 시간 |
|---|---|---|---|---|
| 1,500 | 0.551 | 0.182 | 0.533 | 1.3분 |
| 6,000 | 0.623 | 0.344 | 0.609 | 3.5분 |
| 20,000 | 0.665 | 0.423 | 0.648 | 10.2분 |
| 60,000 | 0.703 | 0.468 | 0.687 | 29.8분 |
| 200,000 | 0.731 | 0.536 | 0.717 | 98.0분 |

| 구간 | dev F1 상승 | dev macro F1 상승 | 시간 배수 |
|---|---|---|---|
| 1,500 → 6,000 | +7.20점 | +16.25점 | ×2.7 |
| 6,000 → 20,000 | +4.21점 | +7.94점 | ×3.0 |
| 20,000 → 60,000 | +3.80점 | +4.47점 | ×2.9 |
| 60,000 → 200,000 | **+2.82점** | **+6.77점** | ×3.3 |

**결정**: +2.82점 ≥ 0.7점 → **학습 문장 수 20만**.

**근거와 해석**
- 상승 폭은 줄어들지만(7.2 → 4.2 → 3.8 → 2.8점) 20만에서도 흔들림보다 훨씬 크다.
- 신조어(NW) dev F1은 6만까지 0이었다가 20만에서 0.23. 드문 태그는 데이터를 늘려야만 배운다 → macro F1이 6.8점 오른 이유.
- 20만도 3에폭에서 아직 오르는 중(0.688 → 0.723 → 0.731). 에폭을 늘리면 더 오를 여지가 있다.
- 그림: `figures/1_학습량곡선.png`

**적용 방법**: 모델 비교(M1·M2)는 이미 6만으로 진행 중이며 그대로 둔다(같은 조건 비교라 순위는 유효). 6만 결과로 상위 모델과 오답 보완 효과가 큰 모델 2~3개를 골라 **20만으로 다시 학습**해 최종 점수를 낸다. 20만 학습은 서버 조각에서 약 1시간 40분, Colab L4에서 약 50분(6만 L4 실측 15분 × 3.3 추정).

## 관찰 1. 점수가 0.7대에 머무는 이유 — 라벨 일관성 (2026-10-22)

AI Hub 안내 페이지의 F1 0.8985는 KLUE-NER(사람이 단 라벨, 인물·장소·기관·날짜·시간·수량)로 잰 값이라 우리 데이터(문화용어·용어·인공물·학문분야·이론·신조어 등) 점수와 직접 비교할 수 없다. 우리 데이터 자체의 라벨 일관성을 split_v1 train 6만 문장에서 쟀다.

| 측정 | 값 |
|---|---|
| 10번 이상 라벨된 개체 문자열(2글자 이상) | 882개 |
| 그중 문장마다 태그가 2종류 이상으로 갈린 문자열 | 113개 (12.8%) |
| 그 문자열들이 단어 시작 위치에 나온 74,718번 중 라벨이 없는 경우 | 25,015번 (33.5%) — '(이름)' 비식별 표시 제외 |

예: 청와대 OG 117 / AF 161 (공식 지침은 OG), 검찰 OG 120 / CV 38, '대표' CV 963번 라벨 vs 라벨 없음 다수, '아이스팩'이 OG로 라벨된 문장.
- 기준선(6만) test 오답: 오탐 2,657 · 미탐 2,501 · 경계 1,469 — 오탐·미탐이 경계보다 훨씬 많다. 모델이 맞게 찾아도 정답에 라벨이 없으면 오탐, 라벨이 흔들리면 미탐이 된다.
- 토큰화 기준 점수 상한(0.97)은 이 라벨 흔들림을 반영하지 않는다. 라벨 노이즈 200건 수동 검수로 "라벨이 틀린 비율"을 직접 재면 실제 달성 가능한 상한을 추정할 수 있다.
- 단, '라벨 없음' 33.5%에는 같은 문자열이 개체가 아닌 뜻으로 쓰인 경우(예: 일반 명사 '대상')도 일부 섞여 있어 모두 라벨 오류는 아니다.
