# CLAUDE.md — 금융 NER 라벨링 작업 폴더 (2팀 NER 프로젝트)

이 폴더에서 Claude의 일은 하나다: **배정된 경제 뉴스 문장에 금융 개체 라벨을 단다.** 사람(팀원)이 세션을 열고 Claude가 라벨을 직접 판단해 단다. 목표는 양보다 **일관되고 정확한 라벨**이다. 이 라벨은 2단계 금융 NER 모델의 학습 데이터(실버셋)가 되고, 5명이 나눠 단 결과를 하나로 합치므로 **모든 세션이 같은 기준으로 단 것처럼 보여야 한다.**

## 반드시 지킬 것
1. **기준은 `GUIDE.md` 하나뿐이다.** 세션을 시작하면 GUIDE.md 전체와 `examples.json` 의 `examples` 를 읽는다. 기준서에 없는 판단을 새로 만들지 않는다. 애매하면 GUIDE 3장 8번(애매하면 달지 않는다)을 따른다.
2. **기준서를 고치지 않는다.** 고칠 점이 보이면 `notes/기준_제안.md` 에 문장 번호와 함께 적고 계속 진행한다. 팀이 정해서 새 GUIDE.md를 배포한다.
3. **데이터 파일(`data/shard_*.jsonl`)과 `examples.json` 을 수정·삭제하지 않는다.** 결과는 `labels/`(내가 쓴 txt)와 `out/`(도구가 만든 jsonl)에만 생긴다.
4. 라벨은 **Claude가 문장을 직접 읽고 판단해서** 쓴다. 규칙 스크립트·정규식·사전으로 자동 생성하거나, 다른 LLM API를 부르지 않는다(비용·품질 기준이 달라진다).
5. 사람 이름, `(이름)` 은 라벨하지 않는다. 문장 원문을 바꾸지 않는다.
6. API 키·개인 정보를 어떤 파일에도 쓰지 않는다.

## 작업 루프 (스킬 `/fin-ner-label` 이 이 순서를 안내한다)
1. `python label_tool.py next --me <이름>` → 다음 묶음(50문장)이 나온다.
2. 50문장을 하나씩 읽고 GUIDE.md 형식으로 `labels/b<번호5자리>.txt` 에 쓴다 (예: labels/b00001.txt).
3. `python label_tool.py add --me <이름> --batch <번호> --file labels/b<번호>.txt`
4. 출력의 **확인:** 줄을 하나씩 본다. 틀린 것이면 txt를 고치고 add 를 다시 실행한다(덮어씀). 맞으면 그대로 둔다.
5. 1로 돌아간다. 사람이 멈추라고 할 때까지, 또는 세션 사용량이 바닥나기 전까지 계속한다.

## 품질 점검 (꼭 한다)
- **세션 시작 시** `python label_tool.py calib --me <이름>` 로 맞추기 10문장을 정답 없이 라벨해 `labels/calib.txt` 에 쓰고 `calib-score` 를 돌린다. F1이 0.90 미만이면 다른 점을 GUIDE.md에서 다시 확인한 뒤 시작한다. 결과 숫자를 `notes/calib_log.md` 에 날짜와 함께 한 줄 적는다.
- **20묶음마다** `python label_tool.py status --me <이름>` 으로 태그 비율을 Claude 기준(DATE 23 / ORG 21 / INDICATOR 14 / RATE 11 / MONEY 11 / FIN_ORG 10 / FIN_PRODUCT 7 / POLICY 3 %, 문장당 약 2.3개)과 비교한다. 어느 태그가 절반 이하나 두 배 이상이면 그 태그 규칙을 다시 읽는다.
- 긴 세션에서 기준이 흔들리지 않도록 **20묶음마다 GUIDE.md 2·3·4장을 다시 읽는다.**

## 자주 틀리는 것 (2,850문장 작업에서 나온 것)
- 증권사·은행 약칭(신영, 대신證, nh, 한국證)을 O로 다는 실수 → FO
- 코스피·코스닥을 O로 다는 실수 → I
- "지난 15일"에서 "지난"까지 넣는 실수 → 15일만. 단 지난해·지난달은 포함
- 단독 "대출"·"보험"·"상품"에 P를 다는 실수 → 달지 않음
- 앞쪽 단어 안에 같은 글자가 먼저 나와 위치가 틀어지는 경우(쇼핑시설…설 연휴) → `설=D@2`
- 범위(25~30%, 1000억~2000억원)를 둘로 쪼개는 실수 → 한 덩어리

## 끝낼 때
- `python label_tool.py status --me <이름>` 결과를 사람에게 보여 주고 다음 묶음 번호를 알려 준다.
- 사람이 요청하면 `python label_tool.py export --me <이름>` 으로 보낼 파일을 만든다.
